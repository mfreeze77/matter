Observed interpretation findings, without independent accuracy claims:

- County technology renewal scored 0.95–0.97 for finance and 0.02–0.03 for

  Non-duplicate irrelevant school-IT sources still had novelty 0.66–0.90;
  novelty alone cannot decide interruption. The intended audience-contribution

- The finance-negative permit scored 0.64–0.69 for finance in all histories,
  disagreeing with the model reference's narrower reading. None of the frozen

- Staffing relevance scored 0.78, 0.80 and 0.71 across histories. It straddles
  the lowest positive candidate. This small run cannot separate history effects
  from ordinary repeat variation; no threshold was changed to accommodate it.
- All stage choices were C (pending proposal/request), with final-action
  probabilities 0.01–0.04. This source set still supplies no positive final-action

  school-purchase prior scored 0.82–0.93. A correction to prior misinformation
  may need attention even when current-source objective relevance is low;
  current relevance alone is not a qualified corrective-silence policy.
