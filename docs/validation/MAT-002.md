## Review decisions and corrections

Independent contract and canonicalization review found and corrected concrete
admission defects before publication:

- No-match results retain considered-but-rejected candidates and an empty
  selection, preserving the actual evaluation context.
- Immutable references require digest pins, and association references use the
  same allowed record kinds throughout commands and stored records.
- Available content cannot pair with an unavailable locator. Host controls
  require host-origin metadata, while authentication remains a host check.
- Exact identifier/digest/decimal patterns reject terminal-newline bypasses,
  and resource cost ceilings reject negative decimal strings.
- Judgments and assessments require the input, evidence, omission, timing,
  resource, and stop-state fields needed to report reproducibility honestly.
  Missing or unproduced artifacts have explicit reasons instead of fabricated
  digests.

The final independent review found no material remaining structural defect in
the MAT-002 scope. The following commands reproduce the main acceptance checks:

```bash
python -m matter render --check
python -m matter validate
python -m unittest discover -s tests -v
node tests/fixtures/canonical/verify.mjs
python -m matter demo all
```

## Qualification boundaries

All fixtures are synthetic. Placeholder reference digests are structural
examples; the canonical vectors separately establish actual byte hashing.
Shape checks do not verify that referenced objects exist, authorize their
access, validate a source locator, establish provider accuracy, or make an
operation durable. The JavaScript program verifies positive canonical vectors,
not a second production engine or strict decoder. These runtime and broader
conformance guarantees remain in their own tickets.
