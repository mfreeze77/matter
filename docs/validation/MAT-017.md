## Requirements exercised

- **AC-1:** two generic compound condition keys; success for B cannot resolve A;
  same-key success in different circumstances is held; corresponding success
  resolves through the actual current qualified assessment.
- **AC-2:** resolve, reassess/redeliver the original occurrence, then introduce a
  distinct later accepted happening. Old delivery and a newly identified older
  happening stay held; real recurrence reopens and retains all receipts.
- **AC-3:** an actual ClaimService correction supersedes the resolution basis,
  invalidates the old lifecycle, and a new current unknown assessment admits the
  profile's unknown transition. Unrelated retraction and refutation are held;
  old resolution evidence is preserved.
- High-confidence typed evidence does not install an undeclared edge or acquire
  a transition capability. An acknowledgement cannot satisfy a human-decision
  edge. Ordinary recovery commits without a user confirmation receipt.
- Late-discovered resolution retains separate known effective and commit
  knowledge times; historical knowledge before discovery remains open.
- Original transition-token scope must cover the complete discovered read
  closure. A later control prevents an old prepared transition from applying.
- State registration, immutable receipt and occurrence slot roll back together
  on registration failure. A real registered queue descendant invalidates in
  the same operation receipt as the state replacement.
- Exact retry and fresh same-basis no-op preserve state/history. A changed
  effective-time request cannot bypass evidence admission via that no-op.
- Future or unknown source availability cannot establish earlier knowledge.
- Immutable definitions bind changed signal semantics to different exact edge
  fingerprints and reject a retraction profile which would assert refutation.

- Transition admission still requires the selected current assessment. The
  immutable transition receipt retains that actual lane's publication proof,
  and current domain-state reads rerun its original source, qualification,
  context and control guards. Lifecycle dependencies bind the original
  assessment/sources rather than the replaceable lane pointer.
- Same-lane equivalent reassessment and original-event redelivery preserve an
  admissible resolved state. Actual source correction and original certificate
  expiry still refuse it; a new certificate does not renew an old judgment.
- Origin selectors now match the actual core set, including `evaluator` and
  excluding nonexistent `model`.
- Non-past effectivity uses the stable admitted assessment knowledge cut;
  an advancing commit clock no longer disables the edge.
- Recurrence reads the prior accepted occurrence's current grouping and checks
  its happening time against the retained original snapshot. Routine membership
  revision is allowed and its actual revision remains a transaction race guard.
