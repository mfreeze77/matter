# MAT-026 validation receipt

## Implemented scope

The typed interface supplies immutable questions, frozen state-bound batches,
adapter capability declarations, exact numeric precision profiles, raw execution
values, whole-batch diagnostics, a bounded injected executor and exact offline
recordings. Choice, rubric Score and proposition probability preserve their
different meanings. See the [API](../semantic-executor.md).

## Executed evidence

On 2026-10-27, Python 3.12.14 in the repository's constrained `.venv`:

`python -m unittest discover -s tests/semantic -v` passed **32 tests in 0.201s**.
This is a focused synthetic interface run; combined repository checks and
independent review are recorded separately by the integrating agent.

After independent review, the malformed-wire negative test was strengthened on
2026-10-27. Each encoding/key case now starts from an otherwise valid complete
response and requires the exact `invalid_response` fault with no diagnostics;
the unexpected action field separately requires `invalid_primitive`. This
prevents missing-answer or unrelated shape failures from masking parser
regressions. The strengthened **32-test** focused run passed in **0.218s**.
No runtime code changed for this remediation.

- AC-1: a subprocess blocks provider SDK/client imports and network connection
  creation, imports the installed module and round-trips a canonical contract.
  All primitive variants and batches serialize without provider extras or keys.
- AC-2: valid distinct primitive shapes pass; missing, duplicate, unexpected,
  malformed and wrong-type IDs invalidate the whole batch while preserving
  valid answer diagnostics. Required fields, exact legends, probability IDs,
  numeric ranges, choice identity and Score distribution compatibility are
  checked without defaults or clamping.
- AC-3: a successful offline evaluation never calls the real storage mutation
  seam; the batch stays unchanged. The API provides no host mutation/delivery
  callback, outputs no action capability, and keeps consequential use false.
  Unsupported primitives, adapter identities, modes and exhausted request
  budgets fail before the injected executor is called.
- AC-4: raw `0.1234567890123456789`, fractional Score, exponent spelling,
  confidence, distributions and residuals survive exact numeric parsing and
  canonical re-encoding. Tests compare original bytes, source hashes, normalized
  strings and framed result digests. A reduced ambient Decimal precision does
  not round the arithmetic. SDK mappings cannot claim original wire precision.

Other focused checks cover deep detachment, ordered question identity, exact
state/packet binding, duplicate JSON keys, invalid Unicode/nonfinite/bool/large
numbers, trusted rounding grids and feasible probability intervals, cooperative
deadline overruns, backward clocks, response limits, recording misses and
exception-message redaction.

## Limits

No live provider, credential access, provider SDK projection, model evaluation,
native transport, persistent receipt, specification registry, certificate
issuance, assessment publication, host action or downstream repository changed.
The host supplies specification identities and eligible source data; MAT-027
and MAT-028 add those later registries/preparation guarantees. Native provider
wire artifacts must be preserved by a future adapter in addition to neutral
projection bytes. Execution deadline checks cannot preempt a synchronous
callback, and injected host code is not sandboxed. Primitive validity does not
establish qualification, source truth or action authority.
