# MAT-015 validation receipt

## Implemented boundary

MAT-015 supplies short consistent snapshot preparation, exact graph/profile/
context bindings, typed staged publication, atomic actual child/judgment pins,
immutable assessment history, independent current lanes, explicit cause
classification, embedded normalized input artifacts and a declared semantic
projection cache. The [API](../assessments.md) documents proposed versus
server-materialized fields and the host's remaining responsibilities.

No core command variant, database migration, host authority receipt, provider
client, audience transport or downstream repository was introduced. The existing
`commit_assessment` operation and durable refusal journal are reused. A generic
storage dependency-error classification seam is integrated separately by root;
its default remains unchanged for existing operations.

## Qualification limits

These tests establish local synthetic publication/cache behavior. They do not
measure provider accuracy, independent corpus labels, production attention
usefulness, preemptive execution cancellation or native application integration.
The host supplies authenticated actors, original tokens, installed binding/
profile/resolver/schema definitions, valid source locator declarations and
explicit claim-label mappings. A cached model judgment never becomes source
authority or permission to act.

`current()` performs fresh guarded reads before returning a result. General
transitive invalidation and automatic recomputation remain MAT-016. Transaction
proof reads are distinct from declared semantic invalidation dependencies;
narrow negative watches are checked by their actual registered predicates.
An interleaving after final read-set preparation may conservatively refuse
publication but cannot make an unchecked attempt current. No provider/cost
measurement is invented from binding invocation counts.

Concurrent cache fills deliberately retain this conservative optimistic-read
contract. A newly appeared row was absent from the original declared pin set,
so the losing assessment receives durable `E_DEPENDENCY_STALE` with its own raw
attempt retained. A new host attempt captures the winning pin, reuses it without
another computation and publishes; exact retry of the old command returns its
historical refusal. The independent review's proposed opportunistic adoption was
not applied because it would bypass the storage port's declared-read contract.
