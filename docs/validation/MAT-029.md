## Limits

configured host classifier, not issued here; source-transform semantics and
free-form host code remain trusted. Completion of a synchronous callback is
cooperative. Trace records are uncommitted; MAT-030 owns persistent attempt

independent review remain integrating-agent gates. These checks establish no
provider accuracy or live user usefulness.
