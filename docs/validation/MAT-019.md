# MAT-019 validation receipt

## Implemented scope

MAT-019 adds an installed immutable attention policy, bounded semantic projection
of actual admitted assessment propositions, deterministic neutral treatments,
immutable decision receipts, registered current decisions and a separately
verified delivered baseline. The baseline is scoped to matter/purpose/audience
identity rather than attention-policy ID. It retains exact actual versions and
the material contract; equivalent policy IDs do not create an uninformed audience.

The existing `assess` envelope and typed request/result extensions are used. The
success body references the actual current assessment. No dummy domain record,
transport send, outbox, recipient directory, provider call or universal importance
score implements the operation. Seven internal schemas bind policy, preparation,
decision, current pointer, delivery milestone, baseline and result.

The view-local `stage(tx, prepared_command)` is used by normal evaluation and
supports atomic integration with the actual timer firing transaction. Original
actor/authority, complete reads, controls, exact contexts, current assessment,
optional lifecycle and original access context remain checked; no token is
recaptured and no semantic binding runs during attention reevaluation.

## Reuse, authority and limits

Read README, canonical MAT-019, lifecycle/core/rules contracts, `matterjevmesh`
delivered-baseline/quietness examples and `matterbrainstormspec`. Intent-graph
`ticket_context` reported no addressing commits or citations; its index was one
commit behind HEAD, so that result was treated as a bounded index observation.
Actual source APIs were inspected and reused: shared assessment currentness,
lifecycle role/current reads, independent context/disposition bindings, original
ControlService guards, source-access/current-history checks, canonical encoding,
existing projections/receipts and registered dependency invalidation. No external
repository state was changed.

Material selectors are explicit bounded code over declared typed propositions,
not a semantic similarity model. Two equivalent typed values can share a material
identity despite different words; this does not establish that arbitrary prose
is equivalent. Conflicting matches stay unknown. A correction traversal is bounded
to 128 links per field; current work cannot silently extend its source scope.

The caller must preserve all original public target/control guards, including
candidate disposition absences, and install the invalidation observer on every
participating host write handle. Raw storage remains privileged. Source metadata
requires exact host grants when source-access enforcement is installed.

Delivered history trusts actual persisted host receipts from explicitly configured
producers/milestones. It does not authenticate a remote provider, observe real
network delivery, infer consumption, establish usefulness, or promise exactly-once
transport. Historical baseline/decision receipts remain separate from current
assessment validity. Source READ restrictions apply at inspection and replay.

All evidence here is synthetic behavioral/interface evidence. No real transport,
private corpus, live model/provider, semantic accuracy study, production attention
budget, user usefulness or downstream live integration was exercised. Canonical
completion remains pending combined gates.
