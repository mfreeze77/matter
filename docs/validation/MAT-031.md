# MAT-031 validation receipt

## Implemented scope

Strict immutable reviewed-method certificate/report contracts, trusted host
catalog install/revocation over the existing control transaction, exact execution
applicability, independent affirmative/negative/abstention decisions, preflight,
real MAT-030 cache classification, actual MAT-029 persisted-view classification,
and the typed `admit_semantic_result` operation. The operation records an explicit
qualification decision and registers real source/certificate/time dependencies.
It adds no record kind, provider transport, issuance pipeline or action authority.
The existing rule QualificationRegistry remains unchanged.

## Acceptance mapping

but failed held-out report remains unqualified with reason `held_out_failed`.
The ordinary operation durably records the refusal while replay remains raw and
nonconsequential. This is the threshold-only Jevcal runtime regression, not a
reuse of its authority implementation.

method-qualified but abstained in the declared undecided region; the actual
MAT-029 gate maps it to unknown. Exact0.1234567890123456789 remains unchanged.
Both independently qualified conflicting heads retain their identities; no truth
or disagreement resolution is invented.

AC-3: the real SQLite host hook records a qualified admission, publishes a real
MAT-015 assessment consuming its pin, and applies an actual certificate revoke
control. Admission and assessment registrations invalidate atomically. Current
assessment reads and cache qualification refuse; original execution, evaluation
and then-qualified admission snapshots remain unchanged and permission-checked

Actual READ denial blocks current/history/idempotent replay. Reuse views point to
the actual original trial, and changed diagnostic DTOs cannot qualify a stage.

## Limits

Configured host reviewers attest their exact report and artifact pins. Runtime
checks consistency, applicability and support; it neither computes confidence
intervals nor establishes that an attestation is empirically accurate. All report
support and lower bounds here are synthetic. No real certificate was issued, no
model accuracy/safety claim was made, and MAT-039/040 release gates remain open.

Host storage/payload ports remain privileged. Proactive transitive invalidation
requires the existing InvalidationHook; registered current gates still check
freshness without it. A method-qualified result is not host permission, source
truth, an identity assignment, a delivery, or an authorized action. No private
corpus, provider/network call, credential access or cross-repository mutation
occurred in this ticket.

## Current-clock and accepted-support remediation

Integrating review reproduced two defects in the first frozen candidate. A caller
could pass an old `as_of` to inspect/preflight after actual certificate expiry.
Those methods now always sample the injected current host clock; an earlier sample
cannot backdate applicability, and a future sample refuses with `E_POLICY_INVALID`.
The historical admission/read APIs retain their existing separate meanings.

The support guard also allowed a report with100 cohort episodes, minimum10,
but only1 accepted decision to qualify. Each declared polarity's minimum is now
explicitly independent accepted episode support: `minimum_episodes <= accepted
<= episodes`. Strict schema annotations and runtime documentation make this
meaning explicit. Counts remain externally reviewed host attestations; no interval
estimation or empirical validation was added.
