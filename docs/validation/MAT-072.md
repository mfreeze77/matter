## Limits

These synthetic checks verify the implemented local ports. They do not establish
production authentication, external ACL synchronization, provider-side retention,
preemptive cancellation, redaction correctness or live usefulness. Raw host
storage/payload handles and free-form host template construction remain
privileged. Hosts must configure current policy, preserve provenance, deliver
revocations through the control path and route protected output through these
ports. No byte inspection can establish the true origin of an arbitrary string.
External I/O already authorized/sent cannot be retracted by a later check.
