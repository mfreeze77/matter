## Consumer handoff

Replace `from matter.access import _public` with
`from matter.access import is_source_access_target`, and update the six calls.
`is_source_access_target(ref)` and `_public(ref)` are the **same callable**.
Pass already validated record/entity/pinned references. This classifies source
access targets; it does not validate inputs, grant access or imply public
availability. False excludes receipts, controls and internal `matter.*`
projections from source grants; it does not authorize their disclosure.
HostAccessPolicy, READ, audience/provider, parent closure, currentness and
revocation checks remain the actual authority. No StateCivics code was changed.

The private helper in the separate delivery module was not refactored here;
this release shares the access classifier between its public and legacy names.
