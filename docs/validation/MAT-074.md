# MAT-074 compatibility closeout

Completed 2026-11-02, SDK **0.1.0.dev21**. This milestone adds compatibility
machinery and conformance evidence; it does not qualify a provider or deploy a host.

## Scope and contracts

The [compatibility policy](../../schemas/versioning.md) adds opt-in envelopes
around existing payloads. Readers preserve optional extensions and reject unknown
required features or exact semantic fingerprints. Consumer-required semantics
can detect stripped or substituted declarations, but declarations are not proof
that the native payload used those rules. Existing schema, integrity, currentness,
access, revocation, budget and qualification checks remain authoritative.

Frozen monitoring 1.0/1.1 and assistant-review 1.0 are unchanged. SQL schema
remains **1**: the manifest exposes the existing checksummed SQLite registry;
no physical upgrade or new host implementation is shipped. Physical format and
data semantics differ: dev20/dev21-written state still cannot downgrade to dev19.
Hosts must enforce their pinned SDK/data compatibility before opening a store.

The strict JavaScript conformance reader shares the original MAT-002 codec,
now in reviewed `conformance/clients/canonical.mjs`. Its importable API has no
startup I/O; `conformance/clients/inspect.mjs` is the separate stdin CLI.
This reader is not a second Matter runtime and is not inside the Python wheel.
All fixtures/databases are synthetic. No StateCivics, crawler, DIAT, Oil, image,
activation or production changes were made.

## Executed verification

- **203 contract tests passed in 7.950s**, including 34 shared compatibility
  cases. Both languages preserve exact decimal strings, canonical integer zero,
  Unicode ordering, null, unknown extensions and opaque timestamp-offset strings;
  native known-time fields retain their existing UTC contract. Accepted canonical
  bytes/digests and refused codes agree, including depth 128/129/1500.
- **28 migration/backup tests passed in 5.177s**. The new episode contains an
  actual superseding claim, a typed unresolved-proposal fixture and an actual
  authorized-but-unknown delivery. A test-only future migration rolls back on
  interruption; its committed upgrade preserves every application row and is
  refused by the older registry. Restoring the verified pre-upgrade backup to a
  new destination recovers exact history and issues no send.
- JavaScript: **26 canonical positives, 8 exact-source vectors and 53 strict
  refusals**, plus invalid digest-kind checks, passed.
- **19 final installed-wheel tests passed in 220.648s**, including all 12
  versioning tests, the migration episode and both MAT-091 regression files.
  Those regressions include capture/edit/capture and ten actual synthetic
  capture handoffs within the existing 197,004-byte upper measurement.
- Full standard suite at `892d03053b3f74f9d47f7e6abebe87d517436003`:
  **1566 tests passed in 1307.074s**. This commit differs from final code/test
  `67271eb6a8460a50d5cad8a6cd7efe4da26d1a29` only in the validation document.

Rollback is a **verified prior-backup restore before any later writes**, not
reverse SQL or a merge of post-backup changes. Hosts must quiesce writers and
account for original external attempts; a restored file cannot establish that
those workers stopped. Unknown remains unknown. The unresolved proposal is a
stored typed fixture, not a newly executed association engine.

## Review and repaired findings

The complete codec/source reviews covered 9/9 and then 10/10 selected files,
using the default two rounds with no warnings. Confirmed findings were repaired:
portable depth limits and producer pre-copy bounds; explicit configuration/refusal
precedence; typed JavaScript refusals without masking unexpected faults; shared
digest framing; malformed UTF-8 size precedence; import-time CLI behavior; and
Node absence no longer skipping Python-only assertions. Two repair reviews then
checked the changes. The final four-file, two-round delta review at `67271eb`
reported **zero findings and zero warnings**. A duplicate run against identical
source also finished clean and adds no independent source coverage.

Markdown and fixture directories follow the existing review exclusions; the
shared codec moved outside fixtures so its complete implementation was selected.
Receipts/documentation and thin fixture runners were checked against actual
outputs. Initial draft fixture/harness errors were corrected before passes;
earlier candidate wheel/check receipts are not final release evidence.
