Status: implementation candidate, SDK `0.1.0.dev21`. Independent review and
installed-wheel closeout remain pending; no completed receiving deployment,

## Scope and existing owners

The [compatibility policy](../../schemas/versioning.md) adds opt-in envelope
admission around existing payloads. Native readers, present controls, access,
policy fingerprints and qualification remain authoritative. Frozen monitoring
1.0/1.1 and assistant-review 1.0 are unchanged. The migration manifest exposes
the existing checksummed SQLite registry; the migration engine and physical
schema version 1 are unchanged.

The JavaScript client reuses the original MAT-002 encoder, extracted into a
shared conformance codec, and adds the missing strict parser. It is a
compatibility reader, not a second native Matter runtime or new host client.
All examples and databases are synthetic. StateCivics, crawler and DIAT
repositories, images and deployment are untouched.
