## What the checks demonstrate

MAT-088: immediate and cumulative route declarations share one semantic wake;
cosmetic wrappers, quotas and retries cannot launch another review. A durable
claim precedes the one permitted host call. Stopped/failed/unknown never becomes
quiet. Currentness, host controls, native cancellation, source/parent access,
provider binding and lens isolation guard admission and completion. A host crash
stays unknown; verified correction-authorized reconciliation records recovery
without resuming work or clearing pressure. Native revisions and worker/provider
rotation do not require lifting cancellation to perform local bookkeeping.

MAT-089: all four host-ledger inputs and derived findings resolve as scoped,
labelled, cited references. Matter persists pointers and its own workflow state,
not findings, memory, raw replies or reports. Deterministic host-rule and JEV
judgments retain distinct
method labels and citations; neither is accepted as a source contribution. The
strengthened host-rule negative case also passed against the installed wheel on
both Python versions (0.741 s / 0.706 s). Quiet and alert completion both
clear only actual reviewed lineage/material versions. Partial review, concurrent
arrivals, corrections, other lenses, contradictory source versions and retained
rule references are covered. Reprints cannot inflate consumed pressure or evict
unreviewed corrections; a genuine reversion uses a new material version.

Metadata reads and append/retry returns check retained native selections under
the current reader. Permission checks are not cached across calls. Oversize
pressure is refused before persistence and preserves the previous readable row;
result verification is separately bounded and never makes an oversized result
quiet. The host still owns trigger scoring, numerical thresholds and retention.
Long-lived metadata-history inspection cost has not been benchmarked; no
performance claim is made for that scan.
