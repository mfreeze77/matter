# MAT-036 validation receipt

## Implemented scope

MAT-036 adds immutable bounded corpus snapshots, strict JSONL ingestion,
source-byte/hash validation, exact scoped episode references, explicit
observation/occurrence/provenance relationships, nanosecond availability
prefixes, independent/teacher/derived label provenance, reviewer disagreement
and unresolved states, and auditable reference-case denominators. External
artifacts remain references; optional authorized host-supplied bytes are
verified without retaining private content.

The six synthetic starter episodes cover routine work, a failure, repeated
reports, a misleading success, a late correction and a quiet interval. The
nine cases include three primary eligible references and six separately
identified excluded/unlabeled/teacher-only/derived-only/disputed/unresolved
cases. No empirical accuracy is inferred from these counts.

## Executed focused evidence

On 2026-10-27, using the repository's constrained Python 3.12 environment:

```bash
.venv/bin/python -m unittest tests.evaluation.test_corpus -v
```

All **27 behavioral tests passed in 0.547 seconds**. Cases include:

- AC-1: unknown observation IDs, altered exact source revisions/hashes,
  incorrect synthetic/external bytes, labels without provenance, duplicates,
  conflicting cross-episode identities, and membership/parent errors are
  rejected before evaluation. Frozen input and detached output mutation cannot
  change the retained digest; label revision/meaning changes do change it.
- AC-2: an old event's correction remains excluded before its later
  availability, with inclusive nanosecond boundaries and explicit unknown
  availability. Included inputs contain no reference labels, case outcomes or
  future report memberships.
- AC-3: declared expected denominators retain independent, teacher and derived
  counts. Conflicting independent reviews are disputed, unresolved labels stay
  unresolved, teacher-only cases cannot enter primary denominators, and a
  teacher disagreement cannot replace an independent reference.
- A copied report retains its original execution and provenance groups.
  Quiet unlabeled cases remain counted. External metadata can be frozen without
  loading private bytes; unverified external bytes cannot enter admitted inputs
  or a primary reference case. Duplicate-key/floating-point JSON and incomplete
  JSONL rows fail strict ingestion.

After independent review, the focused suite passed **29 tests in 0.655
seconds** on 2026-10-27. The follow-up changes use numeric manifest positions
in observation error paths, so descriptive caller observation IDs do not enter
safe `ContractError.detail` or its string form. A marker regression covers
parent, chronology and occurrence-membership refusals. All remaining corpus
error paths were inspected for caller-ID interpolation; paths are static
field names or numeric manifest positions. The original equal-time test is
renamed to describe parent ordering, and a separate pair of valid independent
root observations now verifies the decreasing-availability chronology guard
without an earlier parent/source/boundary error masking that behavior.
