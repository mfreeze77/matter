## Limits

Question registry membership does not establish evidence authority or semantic
accuracy. Syntax lint catches explicit level references and a narrow set of
reference-only aliases; it does not understand arbitrary natural-language
dependencies. Host-declared source manifests are preserved, not independently
verified. Rendering does not authorize source hydration, select eligible evidence,
persist records, issue certificates, call a provider, publish an assessment,
mutate identity or deliver a message. MAT-028 owns bounded source-linked packet
preparation; later tickets own durable receipts and qualification admission.
