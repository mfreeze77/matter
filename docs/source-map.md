## Corrections made explicit

- **Oil invalidation:** run-local version checks and registered dependency invalidation are useful foundations. The current triggered watcher chain does not establish a complete durable matter/source-to-delivery lifecycle. [Store](https://github.com/mfreeze77/oil/blob/3d7c629fd45067de405c1bbae0a2aa0e4036399a/src/intent_oil/cognition_store.py), [watcher](https://github.com/mfreeze77/oil/blob/3d7c629fd45067de405c1bbae0a2aa0e4036399a/src/intent_oil/watcher/chain_check.py), [advice path](https://github.com/mfreeze77/oil/blob/3d7c629fd45067de405c1bbae0a2aa0e4036399a/src/intent_oil/cognition_engine.py).
- **Time:** evidence availability, source publication, effective event time, and assessment time are distinct. A newly received old success cannot resolve a later failure; a late-received qualifying disposition can change the current understanding of an earlier event.
- **Rule authority:** a model's confidence is not a permission, official disposition, identity probability, or direct user instruction.
- **Document ownership:** the governing contracts and Decision 0001 supersede informal implementation shorthand in the older discussions.
- **Implementation claims:** source inspection, synthetic checks, provider evaluations, and live usefulness are separate forms of evidence. The roadmap keeps unexecuted work planned.
