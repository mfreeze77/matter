## Purpose

Plan a crawler-owned adapter that exports the jurisdiction knowledge already captured in definitions and minutes profiles into pinned civic manifests, preserving source-backed relationships and unresolved authority. Receiving legal authority stays an explicit reviewed host input.

## In scope

- Definition/minutes profile export
- Jurisdiction/body/category/effective-period overrides
- Source-backed parent/related-body claims
- Export schema/producer and receiving compatibility receipts

## Scope boundaries

- New jurisdiction onboarding or broad crawling
- Legal-authority inference from titles, category names or parser labels
- Writes to core receiving tables or automatic deployment

## Implementation

1. Inspect the current jurisdiction definition, minutes profile, retained enabling pages and existing T-087/T-104 work before adding an exporter; map exact supported fields and list unavailable ones.
2. Emit immutable manifest bundles with source artifacts/hashes/locators, raw action labels and assertion state; include the producing code revision and source-profile digests.
3. Permit reviewable jurisdiction overrides for explicitly sourced body/category/time differences; retain target body identity during adjourn/reconvene transitions and keep related-entity leads separate.
4. Reference host-reviewed authority records where already supplied through an approved export; otherwise emit an unresolved capability instead of granting authority.
5. Pin the proposed producer/consumer contract and record field-level refusals if the receiver cannot represent it; reuse unchanged bundle digests on replay.

## Acceptance criteria

### AC-1

Exporting an existing minutes profile preserves raw recommendation/final tags without upgrading them to legal authority.

**Verify:** Inspect a generated synthetic/sanitized bundle and validate that review-required capabilities remain unresolved without a host attestation.

### AC-2

Body relationships require source evidence and do not manufacture a separately collected jurisdiction.

**Verify:** Test a verified parent relation, a related-entity lead and a reconvened board in one meeting; only the sourced relation is asserted.

### AC-3

Unchanged export is idempotent and a source/profile change creates a new immutable revision.

**Verify:** Run exporter twice on identical copied input and once after changing an override; compare IDs, digests and predecessor links.

### AC-4

An unsupported receiving field is reported, not silently dropped or converted.

**Verify:** Run the consumer contract against an older pinned version and inspect the compatibility/refusal receipt.
