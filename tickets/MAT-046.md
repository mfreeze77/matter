## Purpose

Specify and implement the neutral validation boundary for versioned civic profiles carrying jurisdiction/body applicability, source stages, scoped capability assertions and reviewed-host authority references. Matter checks integrity and applicability; it does not decide which body has legal power.

## In scope

- Manifest identity/hash and compatibility
- Body/category/effective-period capabilities and uncertainty
- Parent profile references and narrow overrides
- Source and host-attestation provenance

## Scope boundaries

- Hard-coded Kansas/parliamentary law in the core
- Automatic acceptance of crawler final/recommendation parsing labels
- Changes to a receiving civic authority registry

## Implementation

1. Define the JSON Schema and domain adapter types over the common profile contract; include producer/code/schema digest, scope, effective/available-at clocks, source stages and declared capability meanings.
2. Define authority assertions with source links and distinct unreviewed, supported-source, reviewed-host, disputed, withdrawn and unknown dispositions; review state requires a verifiable host attestation reference.
3. Resolve exact pinned parent/override chains with explicit applicability and conflict rules; reject cycles, missing parents and equally applicable conflicting overrides rather than choosing the most permissive value.
4. Supply invented profiles for recommendation-only, act-specific final capacity, unknown capacity and a body that changes during a joint recording; document unsupported rules.
5. Keep legal categories in domain payloads while the core retains neutral rule/dependency interfaces.

## Acceptance criteria

### AC-1

A parser-only final tag never satisfies a reviewed-authority requirement.

**Verify:** Run synthetic manifest/assessment fixtures where identical motion text is evaluated with missing, unreviewed and reviewed authority; only the reviewed applicable case can propose the corresponding host action.

### AC-2

Override resolution is deterministic, time/scoped and conflict-preserving.

**Verify:** Replay the same profiles with shuffled input order, out-of-period review and conflicting body/category scopes; exact decisions/digests match and conflicts remain named.

### AC-3

The neutral Matter package imports and runs without crawler, DIAT or civic enumerations.

**Verify:** Use the core conformance suite and a dependency-boundary test with the civic adapter excluded.

### AC-4

Every accepted manifest is content-bound and refuses broken parent/review references.

**Verify:** Mutate parent digest, source hash and attestation scope independently and verify named refusal before assessment.
