## Purpose

Implement ordinary source-data intake with source identity, payload hashes, availability, and extraction lineage. Retries should be cheap, while changed content must remain an explicit evidential revision.

## In scope

- Observation ingestion and source revisions
- Source-identity conflict receipts
- Immutable payload references

## Scope boundaries

- Trusted instruction interpretation
- Automatic occurrence counting or semantic association

## Implementation

1. Enforce scope/source-namespace/event-ID uniqueness independent of wrapper delivery timestamps.
2. Compare canonical command and original payload digests, returning duplicate or conflict explicitly.
3. Append source revision and supersession records without replacing original content or availability.
4. Expose lightweight unassociated observations without creating a matter for every event.

## Acceptance criteria

### AC-1

Redelivery does not create additional evidence or occurrences.

**Verify:** Replay one event one hundred times with changing transport metadata.

### AC-2

Changed content under one source event identity never silently replaces evidence.

**Verify:** Inspect original bytes and conflict receipt after incompatible submission.

### AC-3

Explicit correction preserves prior content and historical availability.

**Verify:** Query both revisions before and after the correction knowledge boundary.
