## Purpose

Track the current body, agenda item, floor, pending motion/amendment and debate/vote phase as versioned hypotheses. Local procedure is a soft contextual constraint, with branch alternatives and source corrections rather than forced canonical sequences.

## In scope

- Deterministic state transitions over procedural observations
- Pending motion/amendment tree and body/agenda scope
- Ambiguous alternatives and invalidation
- Causal versus bounded retrospective mode

## Scope boundaries

- Training a new large end-to-end model
- Changing acoustic diarization or production identities
- Closing a civic matter from experimental procedural state

## Implementation

1. Define immutable state/transition records with source event references, applied rule/profile digest, prior-state version and alternatives; reuse Matter assessment/dependency interfaces.
2. Implement ordered transitions for recognition, floor release, motion/second, debate, amendment, vote and body/agenda boundaries while retaining explicit unknown/unsupported transitions.
3. Maintain separate nested motion/amendment relations and avoid applying one vote to every pending motion; represent withdrawal, reconsideration and agenda return as new events.
4. Mark dependent later states stale when an earlier source event/profile changes and recompute only the affected interval; retain original historical assessments.
5. Require explicit mode and lookahead window: causal inference uses only evidence available by the decision cutoff; retrospective smoothing is separately named.

## Acceptance criteria

### AC-1

An ordinary recognition-motion-debate-vote sequence produces traceable state without a person assignment.

**Verify:** Run the invented sequence and inspect floor/motion/phase references and authority fields.

### AC-2

Interruptions, omitted seconds and out-of-order source evidence produce alternatives or named unsupported states instead of forced closure.

**Verify:** Exercise local-procedure variations and ambiguity controls through the same tracker.

### AC-3

Correction of an earlier motion/body event invalidates dependent states only.

**Verify:** Replay a mid-sequence correction and compare unaffected intervals and dependency receipts.

### AC-4

Causal mode cannot use later vote/recognition evidence.

**Verify:** Run identical input with different available-at cutoffs and a retrospective variant; verify the declared evidence windows and differing claims.
