## Purpose

Investigate audio-derived pitch/energy/duration patterns while separating the person from room, microphone and recording conditions. Feature computation happens in DIAT on copied audio and never masquerades as a feature that the handoff already computed.

## In scope

- Bounded acoustic feature extraction research
- Voiced-frame/quality and channel metadata
- Room/microphone/shared-channel regimes
- Original-clock and extractor provenance

## Scope boundaries

- Inferring prosody from punctuation alone
- New production embedding space or resolver calibration
- Unbounded GPU/model installation or full-corpus processing without a selected pilot

## Implementation

1. Audit copied audio availability, sample-rate/channel/crop metadata and the existing audio-preparation interfaces; select a small reproducible extractor with documented units, licensing and model/version provenance.
2. Define candidate features only where measurable: voiced pitch contour/range, intensity/energy, durations and local emphasis; store voicing/overlap/noise/clipping coverage and explicit unavailable reasons.
3. Bind all measurements to original recording spans and input hashes, retaining resampling/channel transforms; never reset a crop's source clock.
4. Build room/mic/channel regime metadata from known source information or an explicitly experimental classifier; missing regimes remain unknown and shared microphones receive separate controls.
5. Compare person-heldout, meeting-heldout and channel-regime-shift conditions, including same-person different-mic and different-person same-mic pairs, before admitting features to fusion.

## Acceptance criteria

### AC-1

Prosody is computed from actual audio with input/extractor/clock provenance; non-playable or missing audio produces no fabricated feature.

**Verify:** Run real small authorized crops and synthetic missing/corrupt controls; inspect feature coverage and failure receipts.

### AC-2

Resampling and crop preparation preserve original recording coordinates.

**Verify:** Check a nonzero-offset multi-channel fixture through preparation and feature extraction.

### AC-3

Reported gains survive explicit room/microphone controls or are labeled channel-specific.

**Verify:** Compare same-person/different-mic and different-person/same-mic held-out pairs with matched cohort accounting.

### AC-4

No extracted prosody result changes a production vector, enrollment or identity decision.

**Verify:** Instrument the experimental path and compare production-state digests before/after the pilot.
