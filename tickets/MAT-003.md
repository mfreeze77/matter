## Purpose

Provide an embedded reference store behind a persistence port. Establish concurrency and restart guarantees needed by evidence, assessments, and delivery without introducing a service deployment.

## In scope

- Storage port and SQLite reference backend
- Command journal and atomic receipts
- Migrations and restart/restore behavior

## Scope boundaries

- Hosted database deployment
- Distributed consensus and external delivery guarantees

## Implementation

1. Define transaction boundaries and unique scoped indexes for records, command keys, and projections.
2. Implement command execution with canonical digest, expected read revisions, atomic mutation, and durable receipt.
3. Map persistence failure to semantic errors rather than successful empty queries.
4. Add versioned migrations and a restart/restore harness preserving identities and command outcomes.

## Acceptance criteria

### AC-1

Identical retry returns the original result; changed command content conflicts.

**Verify:** Repeat committed and interrupted commands across process restart.

### AC-2

Competing writers cannot both commit incompatible changes from one expected revision.

**Verify:** Run concurrent transactions and inspect all child writes and receipts.

### AC-3

Persistence failure leaves neither unreceipted mutation nor fabricated success.

**Verify:** Inject failures before receipt, before commit, and during migration.
