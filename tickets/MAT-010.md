## Purpose

Build temporal and coverage primitives for historical assessment and missing-event rules. Failed collection and incomplete coverage must remain visible so the system cannot confuse no observation with verified absence.

## In scope

- Time intervals and knowledge boundaries
- Coverage snapshots and negative watches
- Replacement versus incremental semantics

## Scope boundaries

- Domain calendars and statutory rules
- Global background scanning

## Implementation

1. Validate explicit time fields without substituting ingestion for unknown event time.
2. Represent source/query coverage by source set, interval, snapshot/catalog revision, completeness, and failure reasons.
3. Register negative scopes using typed predicates, knowledge boundaries, and expiry.
4. Permit retirement only under a declared complete replacement scope; retain prior state on failed or partial empty input.

## Acceptance criteria

### AC-1

Late-discovered evidence is excluded from earlier knowledge views while retaining past effective time.

**Verify:** Query one corpus at two availability boundaries.

### AC-2

Incomplete empty sources cannot establish absence or retire facts.

**Verify:** Compare complete, partial, failed, and not-yet-expected snapshots.

### AC-3

New eligible evidence matches a negative watch despite having an unknown original ID.

**Verify:** Insert matching and unrelated records and inspect change signals.
