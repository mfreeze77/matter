## Purpose

Combine eligible acoustic, behavior, procedural and optional semantic evidence into an experimental matter assessment that preserves disagreement and proposes a useful next check. Reuse Matter's judgment/assessment contract and DIAT's frozen candidate boundary; no second resolver or automatic identity write path is introduced.

## In scope

- Evidence-family separated assessment packets
- Conflict/unknown/missing-feature states
- Narrow qualified semantic judgments
- Experimental assessment export and stale-hint invalidation

## Scope boundaries

- Multiplying or adding relevance/compatibility into acoustic identity probability
- Semantic candidate creation outside the frozen pool
- Enrollment, confirmation or production identity assignment
- Automatic user questions for every uncertain segment

## Implementation

1. Map copied evidence records to neutral claims/judgments and bind exact package/source/profile/question/qualification versions and availability cutoffs.
2. Ask focused semantic questions only about ambiguous evidence relationships; compose validated outcomes in code and retain raw acoustic cosine, behavior comparisons, semantic relevance and procedural compatibility separately.
3. Produce anonymous consistency or fixed-candidate experimental decisions, unknown/manual_review/failure outcomes, supporting/counterevidence and a named next permissible check.
4. Track the unresolved concern across observations using a stable matter reference independent of profile/model/recording revisions; distinguish a changed source invalidating an old hint from verified resolution.
5. Export a bounded experimental assessment and attention delta through the existing neutral contracts; recheck source/profile/revocation freshness before displaying a private hint and record emission separately from action.

## Acceptance criteria

### AC-1

An out-of-pool candidate or unqualified semantic result cannot become a resolved experimental identity.

**Verify:** Run typed output and stale/failed qualification controls through the production experiment adapter.

### AC-2

Acoustic/procedural disagreement stays visible and can yield unknown rather than forced consistency.

**Verify:** Use a recognized-chair cue conflicting with the acoustic pool and inspect the named conflict and permitted next check.

### AC-3

Source/profile changes invalidate dependent private hints without rewriting earlier assessments.

**Verify:** Change an input digest or revoke a reference between selection and emission; verify withheld reason and historical receipt preservation.

### AC-4

The integration performs zero enrollment, confirmation or core-service mutation.

**Verify:** Instrument clients/write methods and compare state before/after a representative synthetic and authorized private run.
