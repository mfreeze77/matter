## Purpose

Create one evaluator contract for deterministic functions and future semantic providers. Make unknown, disagreement, and execution failure explicit so downstream policy cannot mistake unavailable judgment for no important concern.

## In scope

- Immutable rule definitions and binding registry
- Bounded inputs and typed results
- Deterministic adapter and recorded external results

## Scope boundaries

- Jev or other provider client
- Provider accuracy certification

## Implementation

1. Implement versioned proposition, eligibility, precondition, and output-implication definitions.
2. Expose a binding interface that returns receipts and proposals without mutable core access.
3. Separate execution_status, evaluation_status, semantic_output, and qualification_status.
4. Validate output labels, cited IDs, admissible states, and consequence permissions before downstream use.

## Acceptance criteria

### AC-1

A timeout cannot satisfy a negative semantic prerequisite.

**Verify:** Feed a fake timeout into a required downstream judgment.

### AC-2

Deterministic and recorded semantic bindings share one neutral input contract.

**Verify:** Run packet validation through both bindings without application fields.

### AC-3

Unknown output labels and nonexistent evidence IDs are refused.

**Verify:** Exercise structurally plausible but semantically invalid responses.
