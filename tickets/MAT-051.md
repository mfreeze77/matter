## Purpose

Establish the private copied/exported corpus and measure the user's reported approximately 315-hour recurring-speaker opportunity. Produce immutable manifests and allowlisted experimental views without retriggering transcription, calling core services, or reading gold labels into model inputs.

## In scope

- Existing package validation and source-copy audit
- Actual hours/usable-spans/provenance/roster/feature inventory
- Original-clock neutral views
- Separate private labels and upstream result custody

## Scope boundaries

- Running the full corpus or buying inference automatically
- Fetching or modifying core project data
- Promoting upstream identities to labels or enrollments
- Claiming the reported hours/person count is verified before inventory

## Implementation

1. Select existing copied meeting-package directories and validate them with the existing DIAT handoff interface; hash every source and retain package/producer/schema versions.
2. Inventory original recording duration separately from unique provenance-group duration, usable diarized speech, meeting/body count, observed tracks, claimed people, verified references and label availability; report overlap and missing artifacts.
3. Construct blind consistency and frozen-candidate views from explicit neutral field allowlists; withhold upstream result names, original label-bearing transcripts and independently held outcomes from model-visible files.
4. Keep occurrence, availability, import and identity-verification clocks separate and state when historical replay is impossible; preserve package-local IDs versus DIAT vector IDs.
5. Write private immutable corpus/view manifests and a synthetic public example; refuse overwrite and ensure all real artifacts remain under ignored data/meeting-matter/.
6. Begin inventory and blind-view preparation with existing DIAT handoff tools after the scaffold; later MAT-062 and MAT-063 enforce common evaluation compatibility, frozen cohorts and leakage qualification before comparative claims.

## Acceptance criteria

### AC-1

The inventory distinguishes user-reported scale from measured unique/usable source coverage.

**Verify:** Run on a small copied sample with duplicate recordings and missing audio; check separate reported and verified fields and no fabricated total.

### AC-2

Blind model inputs contain only allowlisted fields and no upstream identity/gold-label payloads.

**Verify:** Inject sentinel names into result files, original transcripts and reviewer labels; assert absence from built input bytes while audit artifacts remain retained privately.

### AC-3

Original recording clocks, source hashes and package IDs survive view assembly.

**Verify:** Use a cropped recording beginning at a nonzero offset and a multi-meeting file; compare normalized intervals and reject mismatched hashes.

### AC-4

The assembler performs no provider/core/database/enrollment write operation.

**Verify:** Run with those clients disabled and write-path/network instrumentation; only the declared private output is created.
