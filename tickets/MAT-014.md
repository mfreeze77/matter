## Purpose

Build a small typed rule planner and executor. Preserve dependencies between association, evidence, consequence, and attention while permitting bounded concurrency for genuinely independent work.

## In scope

- Validated acyclic rule graph
- Conditional execution and blocked-path receipts
- Deterministic conflict resolvers and shared budgets

## Scope boundaries

- Automatic joint-probability inference

## Implementation

1. Compile typed dependency edges and validate conditional cycles and accepted predecessor states.
2. Schedule independent nodes within shared limits and build dependent inputs only after qualification.
3. Record skipped, blocked, cancelled, and unresolved paths with actual input references.
4. Apply explicit conflict resolvers, preserving original disagreement and mandatory gates.
