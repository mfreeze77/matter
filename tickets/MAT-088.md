## Purpose

Define a small versioned adapter contract where a Matter/JEV material-change trigger wakes the user-specific assistant for optional deeper investigation and a decision about reporting or interruption. This internal review is distinct from an end-user alert and from the existing capture/delivery baseline. The discussion has not frozen fields, thresholds or an assistant runtime.

## In scope

- Internal review request and typed review result semantics, with exact source/context/access and outcome provenance.
- A bounded single assistant pass using existing host tools, separate from consequential publication or production delivery.
- Both immediate decisive-event and accumulated-context review triggers are required; scoring semantics, thresholds, review outcomes and assistant runtime remain unresolved.

## Scope boundaries

- Implementation, provider/tool execution, client-data processing or deployment as part of this planning commit.
- New assistant/model client, MCP server, tool wizard, source index, database, queue or general orchestration framework where existing owners supply the capability.
- Changing frozen monitoring 1.0/1.1 semantics silently; production alerts, formal qualification, DIAT or unrelated Oil work.

## Required test cases

- Wake-up alone does not advance communicated/captured-for-user knowledge.
- A decisive new source correction or deadline can request fresh review despite an earlier quiet/handled decision.
- A failed or unavailable review is unknown, not an irrelevance judgment.
- A decisive client-adverse development does not wait for accumulation.
- One later fact can change the interpretation of earlier quiet findings; do not require keyword counts to reach a universal threshold.
- Alert and no-alert review both clear reviewed pressure; neither deletes evidence, resolves the matter automatically or implies the user read the research.

## Risks

- Treating a bubble burst as delivery can fabricate the user baseline.
- A universal importance score or unbounded agent loop would recreate complexity before usefulness is shown.
