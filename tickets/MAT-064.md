## Purpose

Define and collect independently reviewed outcomes for anonymous consistency, procedure/floor/agenda transitions, fixed-pool identity decisions and useful attention. Machine hypotheses are not labels; uncertain/unresolvable cases and quiet misses remain visible.

## In scope

- Annotation guide and reviewer data boundaries
- Independent double review/adjudication
- Per-task metrics and grouped uncertainty
- Useful/late/repeated/missed hint outcomes

## Scope boundaries

- Using upstream accepted/reviewed machine status as gold
- Hiding disputed labels or selecting only easy recurring speakers
- Treating emitted hints as proven consumed/actionable

## Implementation

1. Write an annotation guide defining tasks, available evidence, temporal mode, uncertain/unresolvable outcomes and source-span labeling; freeze it before held-out inference.
2. Prepare separate reviewer packages from private sources with randomized case ordering and no experimental predicted answers; record reviewer identity/process and disagreements.
3. Collect independent floor/role/agenda and anonymous track-consistency labels plus verified identity labels only where separately supportable; adjudicate without silently forcing consensus.
4. Define useful attention as an evidenced contribution to a next check/decision, distinct from emission/consumption/action; review a sample of quiet cases for missed intervention.
5. Compute per-meeting/provenance-group quality, agreement and uncertainty and report sample support for unknown guests, overlaps, chair changes, shared mics and procedural exceptions.
6. Prepare independent annotation and report formats using existing DIAT tooling without waiting for the full generic evaluator; integrated comparisons remain gated by MAT-062 and its common split, outcome and leakage prerequisites.

## Acceptance criteria

### AC-3

**Verify:** Generate a report where these outcomes disagree and verify no single aggregate hides the distinction.

### AC-4

Usefulness claims include quiet-case misses, timing and observed action scope.

**Verify:** Review emitted and withheld sample episodes with source evidence and record consumed/actioned/unknown independently.
