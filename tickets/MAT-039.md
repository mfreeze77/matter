## Purpose

Add an explicitly selected provider replay mode over the same frozen packets used offline. The runner observes the real adapter and model while leaving host state and delivery untouched, recording all attempted calls and failures so it can support later threshold and drift analysis.

## In scope

- Configured provider-shadow runs, budgets and immutable output references
- Requested/resolved model and full response accounting

## Scope boundaries

- Automatic paid runs from default checks
- Production delivery or automatic decisions from unqualified outputs

## Implementation

1. Require an explicit provider mode, supported adapter, model request, corpus scope, credential source, call/time/cost limits and external result destination.
2. Perform configuration validation without dispatching a call; missing credentials or unsupported configuration produce a not_run result with a reason.
3. Run frozen packets with bounded concurrency and retries, retaining exact request, response, usage, model-resolution and fault receipts.
4. Separate cache replay from fresh provider observations and preserve repeated identical calls as a nondeterminism measurement rather than evidence independence.
5. Generate reports that identify unqualified judgments and confirm no host action or audience delivery occurred.

## Acceptance criteria

### AC-1

A missing credential or unselected provider cannot trigger a fallback call or synthetic result.

**Verify:** Attach action/delivery spies during a provider-shaped integration run and assert no calls.
