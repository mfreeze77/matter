## Purpose

Prepare immutable per-person and anonymous reference profiles across recurring meetings, respecting historical identity verification, recording groups, speaking mode and roster/role changes. Reuse the behavior module; do not update production enrollment banks or treat the recurring roster as a closed identity universe.

## In scope

- Copied verified-reference and anonymous profile views
- Roster/person/role-version provenance
- Mode and time-regime stratification
- Group-balanced coverage and unknown participants

## Scope boundaries

- Automatic enrollment from roster membership or a recognition cue
- Production behavior/profile-service writes
- Treating source-model identities as human ground truth

## Implementation

1. Import copied enrollment/verification snapshots with explicit source IDs and verification/link-availability timestamps; absent history forces retrospective or anonymous-only use.
2. Build profile manifests through existing pure behavior extraction/aggregation interfaces, preserving original source spans and separating prepared, spontaneous and unknown mode.
3. Record roster, attendance and chair/member/staff/witness role intervals as distinct contextual evidence with known/unknown scope; include guest, substitute and never-enrolled speakers.
4. Report raw samples/turns/hearings and independent provenance-group counts for every feature family and reference gap; control long meetings and repeated sources through group balancing.
5. Freeze profile digests and training cutoff for each experimental run; retain predecessor/revocation references without recomputing old run inputs from live DIAT state.

## Acceptance criteria

### AC-1

No reference can enter a strict historical profile before its evidence and verified identity link were available.

**Verify:** Test future/missing verification/link clocks and assert explicit exclusion or mode refusal.

### AC-2

Prepared/spontaneous/unknown modes and independent source groups retain their current separation.

**Verify:** Compare pure-profile outputs against existing behavior fixtures and new copied-reference manifests.

### AC-3

Guest or unknown speakers remain eligible query cases without being forced into the reported recurring roster.

**Verify:** Run fixed-candidate/anonymous tests with roster turnover and an unenrolled participant.

### AC-4

Repeated references and long meetings do not silently dominate profile evidence.

**Verify:** Use one duplicated hearing group and one independent group with unequal turn counts; verify coverage and declared weighting.
