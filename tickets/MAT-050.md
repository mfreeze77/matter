## Purpose

Build independent, source-linked civic conformance and temporal replay evidence demonstrating correct unresolved states, retained valid actions and compatible receiver proposals. Passing synthetic parsing tests must not be relabeled as legal or live receiving acceptance.

## In scope

- Frozen synthetic and authorized sanitized cases
- Profile/authority/identifier/time adversarial controls
- Producer-consumer contract compatibility
- Independent expected outcomes and release limitations

## Scope boundaries

- Claiming jurisdiction-wide collection completeness
- Production import, data migrations or publication
- Inventing authoritative outcomes when source rules are unavailable

## Implementation

1. Construct an adjudicated fixture manifest with source hashes/locators, exact profile and receiving schema pins, explicit expected claim/assessment outcomes and uncertainty labels.
2. Cover joint sittings, changed authorities, recommendation/final separation, legal identifiers, failed motions, source corrections and availability cutoffs in chronological episodes.
3. Run the actual export adapter, profile composition, assessment and delivery-revalidation path; keep deterministic, provider and receiving results in separate sections.
4. Apply mutations to authority-review, scope, temporal and coverage guards, with positive controls retaining an applicable reviewed action and a new useful deadline.
5. Publish a bounded qualification receipt and unresolved receiver dependencies; require separate repository acceptance before a real import/deployment can be claimed.

## Acceptance criteria

### AC-1

All listed authority/time/identity negative controls remain unresolved or refused and applicable positives survive.

**Verify:** Run the frozen corpus through the production path and compare semantic outputs to independent labels.

### AC-2

Removing key authority/availability/scope guards is detected by real assertion failures.

**Verify:** Execute named source-reversion or mutation controls against representative positive/negative cases; retain exact code and corpus hashes.

### AC-3

Replay reports what was available then without overwriting later corrected understanding.

**Verify:** Compare as-of and current views for a late published correction and a future authority attestation.

### AC-4

The report separately names contract validation, source completeness, provider judgment and receiving acceptance.

**Verify:** Review a generated release receipt with unrun receiving steps explicitly not_run and no implied live deployment.
