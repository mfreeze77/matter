## Purpose

Create a host control lane alongside ordinary evidence. Stop, correction, scope, and permission changes take effect immediately under host authority while observed documents and model responses remain data.

## In scope

- Authenticated control envelope and authority references
- Scoped dispositions and control epochs
- Pending-work cancellation hooks

## Scope boundaries

- Identity-provider integration
- New permission or closeout ceremonies

## Implementation

1. Define a host-authenticated interface inaccessible through observation payload fields.
2. Commit control effect, epoch, and receipt before optional matter recording.
3. Provide scoped authority checks for association, merge, transition, reads, and delivery.
4. Propagate cancellation to commit and dispatch checks without asking users to close ordinary matters.
