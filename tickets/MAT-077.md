## Purpose

Turn the reference package into a reproducible developer dependency with documented support and automated checks. Preserve source and license provenance for harvested components and keep qualification fixtures distinct from private data.

## In scope

- Supported Python versions, package assets, CI matrix and reproducible build evidence.
- Third-party source/license inventory and dependency update checks.

## Scope boundaries

- Deploying or modifying a downstream project as part of this planning ticket without that implementation task.
- Treating synthetic checks as evidence of live provider or user outcomes.

## Implementation

1. Extend the scaffold checks to production schemas, runtime tests, public conformance fixtures and packaging installation from built artifacts.
2. Record exact reused components, licenses, local adaptations and upstream versions.
3. Verify installation and operation from a clean environment without accidental checkout-only dependencies or private files.

### AC-1

The built artifact contains all promised public schemas and runs supported operations outside the source checkout.

**Verify:** Build and install in a fresh environment and execute documented SDK examples against packaged assets.

**Verify:** Introduce controlled mutations in a temporary test branch or local workflow equivalent and record the expected failing checks.

**Verify:** Inspect archive contents and compare the source/license manifest to every vendored or adapted component.
