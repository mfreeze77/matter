## Purpose

Extend the existing identity-context eligibility and label firewall to procedural, institution, roster and longitudinal feature evidence. Strict historical replay must reflect source and identity-link availability; retrospective smoothing and unknown chronology remain explicitly separate.

## In scope

- Eligibility before ranking/truncation
- Hearing/provenance/equivalence exclusions
- Evidence and identity-link clocks
- Model-visible allowlists and causal/lookahead contracts

## Scope boundaries

- Assuming an old media date proves historical availability
- Treating exact file hashes as complete re-encode detection
- Using ground truth or later machine corrections to build candidate/profile packets

## Implementation

1. Reuse current source/provenance/equivalence maps and exclusions; build connected groups before person/feature filtering so aliases through unenrolled recordings remain excluded.
2. Require strict-historical cutoff witnesses for query evidence, acoustic candidates, enrollments, profiles and any person-conditioned evidence links; unknown chronology refuses that mode.
3. Add profile-training membership and procedural/agenda lookahead checks, including later recognition, future chair role, final minutes and corrected source labels.
4. Keep original transcripts/upstream results private and allow only explicitly approved neutral fields into each condition; detect sentinel labels in titles, names, filenames and source-derived summaries.
5. Create adversarial fixtures and production-caller mutation tests for each gate; report exclusions and effective coverage without upgrading empty retrieval to evidence of absence.

## Acceptance criteria

### AC-1

All known query/hearing/provenance aliases are excluded before top-K or candidate conditioning.

**Verify:** Use a transitive alias bridge through an unenrolled recording plus re-encoded-equivalence metadata; compare eligible/ranked lists.

### AC-2

Future or unknown evidence/identity-link availability cannot enter strict historical packets.

**Verify:** Run independent clock perturbations on source, enrollment and person association and assert named refusal/exclusion.

### AC-3

Gold identities and upstream machine names are absent from blind build/inference views.

**Verify:** Inject sentinels into reviewer labels, result files, original transcript metadata and derived summaries; scan actual packet bytes.

### AC-4

Causal and retrospective modes record distinct permitted context and cannot be mislabeled.

**Verify:** Run a later-turn disambiguation case under zero and bounded lookahead; verify manifest/report mode and available input differences.
