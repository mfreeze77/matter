## Purpose

Create the evaluation corpus contract before collecting model results. Each episode must preserve the sequence of available observations, source and occurrence relationships, reference outcomes, reviewer disagreements, and the status of its labels so later comparisons have an auditable denominator.

## In scope

- Episode manifests, source hashes, availability timestamps and labels
- Synthetic repository fixtures and external private-artifact references

## Scope boundaries

- Importing production data into this repository
- Treating teacher-model labels as independent truth

## Implementation

1. Define episode boundaries, source snapshots, exact observation/occurrence IDs, task scope and evidence availability separately from event time.
2. Represent ground-truth association, recovery and attention labels with reviewer identity or role, evidence references, disagreement and unresolved status.
3. Add a synthetic starter corpus covering routine work, real failures, retries, misleading successes, late corrections and meaningful quiet periods.
4. Create ingestion validation for externally stored reviewed episodes without copying private session text, roster data or audio into tracked fixtures.
5. Freeze and hash the manifest before evaluation and preserve explicit counts of eligible, excluded and unlabeled cases.

## Acceptance criteria

### AC-1

Every evaluated observation and label resolves to the frozen episode and source revision.

**Verify:** Validate manifests and reject unknown IDs, broken source hashes and labels without provenance.

### AC-2

Late publication cannot become visible through an older event timestamp.

**Verify:** Use an old event published after the cutoff and inspect the replay prefix.

### AC-3

Teacher-generated, disputed and independent labels remain separately identifiable.

**Verify:** Load all three label types and verify that only the declared eligible set enters primary accuracy denominators.
