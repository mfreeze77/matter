## Purpose

Reduce repeated immutable snapshot validation without caching authorization, revocation, currentness or dependency decisions. Ship separately after the dev16 freeze.

## In scope

- Cache successful checks by locally recomputed content digest plus exact bytes, schema version and validator/registry identity; bound process memory and return detached decoded values.
- Retain strict canonical input, stored-row integrity, current head, access, revocation, dependency and capture guards.
- Measure the unchanged consumer prototype without cProfile, cold and warm before/after; record the environments, phase times and workload limitations in a later SDK build.
