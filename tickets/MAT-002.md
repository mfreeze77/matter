## Purpose

Turn the governing prose into executable structural contracts and golden vectors. Keep original source bytes distinct from normalized envelopes, and establish interoperable identifiers, revisions, timestamps, and failures before persistent state is built.

## In scope

- Core record and operation schemas
- Canonical encoding and digest vectors
- Schema compatibility and semantic errors

## Scope boundaries

- Provider response formats
- Domain payload interpretation

## Implementation

1. Inventory required fields, conditional references, extension namespaces, and result unions from the contracts.
2. Implement strict canonical encoding and decoding, rejecting duplicate keys, invalid Unicode, floating numbers, and unsafe integers.
3. Define versioned error results and explicit unknown-time reasons without inventing domain conclusions.
4. Publish cross-language golden input/byte/digest vectors and a schema compatibility matrix.
