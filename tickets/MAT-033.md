## Purpose

Implement a small original family catalogue for ambiguous observation association and claim-relative evidence interpretation. The family produces shadow judgments over frozen candidate packets; it must preserve uncertain associations and cannot change identity or provenance merely because text is similar.

## In scope

- Same/related/different/insufficient matter relations
- Support, contradiction, qualification and asserted-versus-established evidence

## Scope boundaries

- Automatic merges or confirmed speaker identity
- Replacing deterministic exact identifiers with model scores

## Implementation

1. Define a fixed outcome set for each bounded candidate comparison with scope and identifiers resolved before semantic evaluation.
2. Define separate claim-relative predicates for support, contradiction and qualification, allowing compatible dimensions to coexist.
3. Bind each result to claim, candidate, packet, occurrence lineage and question revision, preserving the original observations.
4. Emit proposed associations and unresolved reasons for the core association policy; do not write accepted merges directly.
5. Add synthetic and labeled episode cases distinguishing shared topics, the same continuing matter, a repeated occurrence and independent corroboration.

## Acceptance criteria

### AC-1

Topic similarity cannot automatically establish same matter, same occurrence or shared person identity.

**Verify:** Evaluate fixtures with identical wording across different tasks, executions and people and inspect proposed relations.

### AC-2

A source assertion is distinguished from evidence that the asserted event occurred.

**Verify:** Compare planned funding with an authoritative award document under the same claim.

### AC-3

Support and qualification can coexist without an invalid exclusive-choice collapse.

**Verify:** Use a passing unit test that supports one behavior but leaves integration verification unresolved.
