## Purpose

Represent observed and inferred procedural events with exact original-clock evidence, body/agenda context, alternatives and applicability. This contract supports formal-meeting learning while keeping parliamentary concepts out of Matter's core.

## In scope

- Recognition/motion/second/debate/vote event records
- Body/agenda/phase references and evidence spans
- Observed versus inferred status
- Profile version/availability and ambiguity

## Scope boundaries

- Assigning legal effect to a spoken motion
- Verified voice identity from a recognized name
- A universal Robert's Rules implementation assumed for every jurisdiction

## Implementation

1. Define a strict DIAT experimental event schema over neutral observation/evidence references, including event family, span, source/package IDs, raw cue, alternatives, extractor/model version and uncertainty.
2. Separate session/body, agenda, floor, motion/amendment, discussion, vote and exception event families; preserve multiple events and quoted/hypothetical speech without automatic occurrence claims.
3. Accept profile applicability references from the crawler-owned export and preserve absent/unknown procedures; define optional second/threshold fields without filling defaults from generic parliamentary knowledge.
4. Provide an exporter to Matter's neutral evidence/claim contract with experimental authority and no person-resolution write capability.
5. Create invented sequences and annotation examples with actual/suspected/missing events and interval overlaps.

## Acceptance criteria

### AC-1

Every event retains its source span, extraction version and observed/inferred distinction.

**Verify:** Round-trip representative event records and verify linkage to original-clock turns and source hashes.

### AC-2

Quoted or hypothetical motion text and recognition cues do not become votes or verified speakers.

**Verify:** Test exact phrase controls in quotation, discussion and actual event contexts; preserve ambiguity when evidence cannot distinguish them.

### AC-3

Unsupported local procedure remains unknown without falling back to a universal rule.

**Verify:** Validate a profile with no second requirement and another with missing rules; outputs differ only by supported profile evidence.

### AC-4

The export validates through neutral Matter schemas without a DIAT dependency in the core.

**Verify:** Run contract fixtures through the core and the independent DIAT serializer.
