## Purpose

Extend the existing evaluator with a separately versioned, preregistered ablation family while preserving A/B/C/D unchanged. Measure each new feature and selected interactions on the exact same frozen queries/candidates, including difficult/missing-feature cases and negative outcomes.

## In scope

- Unchanged A/B/C/D replay baseline
- Separately named procedure/grammar/prosody/agenda factors
- Common-cohort and availability reporting
- Paired per-meeting quality/cost and uncertainty

## Scope boundaries

- Silently redefining B or D to include new features
- Selecting thresholds or configurations on held-out labels
- Dropping hard queries separately for each condition
- Launching every possible combination or the full reported corpus by default

## Implementation

1. Freeze a run manifest containing original A/B/C/D packages, common query/candidate/roster/configuration hashes, independent grouped split and factor definitions selected on development data.
2. Add named conditions such as A+procedure, B+procedure and D+procedure; represent lexical/motif removal as explicit ablations of B rather than claiming those existing features are new.
3. Select a bounded factorial subset for grammar, prosody, timing/interaction, institution and agenda context, with recorded hypotheses and maximum calls/bytes/cost.
4. Retain one query inventory across conditions; record feature-unavailable outcomes and both common evaluable cohort metrics and all-query coverage.
5. Report wrong-name/unknown/anonymous-switch/procedure/attention metrics, paired differences and group-level uncertainty alongside extraction/provider cost; include failures and no-improvement results.

## Acceptance criteria

### AC-1

Every condition shares the exact common query/candidate input and baseline A/B/C/D semantics remain unchanged.

**Verify:** Validate package hashes and compare common fields; mutate a candidate or query span in one condition and require refusal.

### AC-2

Held-out labels cannot influence factor/threshold selection.

**Verify:** Verify development-selection manifest timestamps/digests and run label-sentinel tests at build/inference stages.

### AC-3

Missing-feature queries remain in cohort accounting and cannot silently improve accuracy by exclusion.

**Verify:** Use an intentionally missing-prosody subset and compare all-query versus evaluable-cohort denominators.

### AC-4

Reports expose incremental gains, harms, uncertainty and total work on grouped independent units.

**Verify:** Inspect paired meeting-level outputs and reproducible report replay with zero fresh provider calls.

## Risks

- Many factor combinations create post-hoc selection bias and excessive cost.
- The recurring population may yield high apparent accuracy with poor unknown-speaker behavior.
